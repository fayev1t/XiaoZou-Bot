# 工具：`reflect`

## 功能

`reflect` 写下当前这一版自我认识，**完整替换**上一版。写入后，该文本作为
`## 反思` 一节出现在后续每一拍的输入里，直到下一次调用把它整段换掉。

它是除任务之外第二个跨拍留存的装置，两者分工不同：任务承载**未竟之事**，
有 `complete` / `fail` 收束条件；反思承载**对自己的认识**，没有终点，只会被
后来的版本改写。不要用任务记录自我认识（它收束不掉），也不要用反思代替任务
（它不会提醒任何待办）。

本工具不发送消息、不改变群内任何状态，其他人看不到它写下的内容。

## 参数

- `text`：必填字符串，新一版自我认识的完整正文。去除首尾空白后不得为空，
  且不得超过 600 字。

正文是**替换**而不是追加：新版本里没写的内容即从此消失。因此每次都应当读着
`## 反思` 现有正文重写一遍，保留仍然成立的部分、改写已被推翻的部分。

## 返回

```json
{"written": true, "chars": 128}
```

## 失败

- `invalid_arguments`：`text` 缺失、非字符串、去空白后为空，或超过 600 字。
  超长**不会**被截断，整次调用失败——半截正文会在下一拍被当作完整想法读到。
  失败时 `reason_code` 取 `text_not_str` / `text_empty` / `text_too_long`。

## 调用限制

每段程序最多出现一个 `reflect` 调用点。

## 权限与作用域

无最低权限要求，所有 scope 可用。
